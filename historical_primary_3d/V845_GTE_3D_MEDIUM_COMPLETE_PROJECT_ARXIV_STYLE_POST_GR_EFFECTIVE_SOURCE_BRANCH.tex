The operatorial core and Z-line all-sigma results remain the defensible computational layer. The new branch asks a narrower question: if a compact static spherical toy metric is inserted into standard general relativity, what effective stress-energy source is required, and can that source be interpreted as real matter?

The branch locks the effective-source formulas for $f(r)=1-2Gm(r)/r$, verifies Schwarzschild and de Sitter sanity checks, tests compact mass functions, proves exact interval properties of the S5 phenomenological anisotropic-fluid source, explores a formal magnetic nonlinear-electrodynamics reconstruction, and closes the simple canonical scalar route as a negative control. The result is mixed but useful: S5 is a coherent phenomenological GR diagnostic, but not a physical matter model. NED is formally action-like but blocked for exact compact support by the Maxwell weak-field limit; canonical scalar matter is structurally obstructed. No physical route is reopened.
\end{abstract}

\section{GR effective-source diagnostic route}

The V837 branch starts from the static spherical one-function metric:
\begin{equation}
ds^2=-f(r)dt^2+f(r)^{-1}dr^2+r^2d\Omega^2,
\end{equation}
with
\begin{equation}
f(r)=1-\frac{2Gm(r)}{r}.
\end{equation}

In standard GR this corresponds to an effective anisotropic source:
\begin{equation}
\rho_{\rm eff}=\frac{m'(r)}{4\pi r^2},
\end{equation}
\begin{equation}
p_{r,\rm eff}=-\frac{m'(r)}{4\pi r^2}=-\rho_{\rm eff},
\end{equation}
\begin{equation}
p_{t,\rm eff}=-\frac{m''(r)}{8\pi r}.
\end{equation}

This is a reconstruction of the source required by GR. It is not a derivation of a new theory.

\section{Sanity checks}

V838 verified the formulas against standard checks.

\begin{itemize}
\item Schwarzschild vacuum: $m(r)=M$ gives $\rho=p_r=p_t=0$.
\item de Sitter core: $m(r)=\Lambda r^3/(6G)$ gives $\rho=\Lambda/(8\pi G)$ and $p_r=p_t=-\rho$.
\item smoothstep compact matching: $m(r)=M(10x^3-15x^4+6x^5)$ with $x=r/R$ satisfies the intended compact matching at formula level.
\end{itemize}

\section{NED magnetic reconstruction and blocker}

V842 explored a magnetic nonlinear-electrodynamics route under the convention
\begin{equation}
F=\frac{F_{ab}F^{ab}}{4},\qquad F(r)=\frac{q^2}{2r^4}.
\end{equation}

For the magnetic sector:
\begin{equation}
\rho=-L,\qquad p_r=L=-\rho,\qquad p_t=L-2F L_F.
\end{equation}

The formal interior reconstruction gives:
\begin{equation}
L(r)=-\rho(r),
\end{equation}
and
\begin{equation}
L(F)=-A\left(1-\frac{(q^2/(2F))^{1/4}}{R}\right)^2.
\end{equation}

The identity $p_t^{\rm NED}-p_t=0$ passes formally. However, V843 shows that exact compact support requires
\begin{equation}
L(F)=0,\qquad L_F(F)=0
\end{equation}
for $0<F\le F_R$, where $F_R=q^2/(2R^4)$.

This gives $L(F)/F\to 0$ as $F\to 0$, whereas the Maxwell weak-field limit requires $L(F)/F\to -1$. Therefore the exact compact S5 NED route is physically blocked unless the model is changed. A Maxwell-tail alternative breaks exact compact support and creates a different noncompact model.

\section{Canonical scalar obstruction}

V844 checks the simplest scalar route. For a minimally coupled static canonical scalar in a static non-horizon region $f(r)>0$, define
\begin{equation}
X=f(r)\phi'(r)^2\ge 0.
\end{equation}

The stress pattern is:
\begin{equation}
\rho=\frac{1}{2}X+V,\qquad p_r=\frac{1}{2}X-V,\qquad p_t=-\frac{1}{2}X-V.
\end{equation}

Therefore:
\begin{equation}
\rho+p_r=X,\qquad \rho+p_t=0.
\end{equation}

S5 requires $p_r=-\rho$, hence $\rho+p_r=0$. In the $f>0$ region this forces $X=0$ and therefore $\phi'=0$. The scalar then becomes isotropic and vacuum-like:
\begin{equation}
p_r=p_t=-\rho.
\end{equation}

But S5 has
\begin{equation}
\rho+p_t=A\,x(1-x)>0\qquad (0<x<1).
\end{equation}

Thus a simple canonical static scalar cannot reproduce the S5 source pattern. A simple phantom sign variant is also obstructed because it still forces $X=0$. Noncanonical scalar routes are not ruled out, but they remain high-risk and require independent stability gates.

Better for Zenodo or external archival storage:

\begin{itemize}
\item large local results;
\item raw or heavy derived data bundles;
\item 400 MB or multi-GB archives;

\end{itemize}

Do not publish without review:

\begin{itemize}
\item third-party raw data with unclear redistribution rights;
\item private paths, usernames, API keys, tokens, or local metadata;
\item licensed data not meant for redistribution.
\end{itemize}
